# Spotlight HD Media

Website and digital platform for Spotlight HD Media, a Melbourne-based creative studio specialising in video production, photography, drone cinematography, social media content, and brand storytelling.

## Project goals
- Showcase services, portfolio work, and client outcomes
- Generate high-quality enquiries and project bookings
- Present a professional, premium brand presence
- Support future case studies, blog content, and SEO

## Planned pages
- Home
- Services
- Portfolio
- About
- Contact
- Insights / Case Studies
