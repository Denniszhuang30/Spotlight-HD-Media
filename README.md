# Spotlight HD Media

Public-safe planning repository for the Spotlight HD Media website and digital platform, a Melbourne-based creative studio working across video production, photography, drone cinematography and brand storytelling.

## Current status

Temporary project setup for cloud onboarding. This repository is not a finished website or a production-ready application. The existing local project is still a draft and has not been uploaded here.

At this stage, the repository contains documentation only. The technology stack, application source, build commands and deployment settings are still to be confirmed.

## Project goals

- Present services and relevant, permission-cleared portfolio work.
- Help prospective clients understand the work and make project enquiries.
- Build a clear, professional brand presence.
- Support future case studies, insights and search visibility.

## Proposed pages

- Home
- Services
- Portfolio
- About
- Contact
- Insights / Case Studies

These are planning ideas, not completed pages or an approved final site structure.

## Cloud onboarding

Use the `main` branch when connecting this repository. The initial README provides a starting point for cloud setup; it does not provide runnable website code.

Before implementation, confirm the intended project, technology stack and files suitable for this public repository. Add installation, development, testing and deployment instructions when the application exists.

## Privacy and publishing boundaries

Do not commit API keys, access tokens, passwords, `.env` files, private client briefs, contracts, invoices, tax or bank records, or exports of private Obsidian and Notion workspaces.

Only add reviewed, public-safe project files. Client footage, photography, logos, testimonials and case-study claims require the appropriate permissions before publication. This repository is not a backup of private business records.
